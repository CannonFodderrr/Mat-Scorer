MatSide is Companion App to Strategic Wrestler (MatScout)

Use with Phone or Tablet to Record Live Matches and Manually Score

Removes the Need for Paper Bout Sheets

Upload Match JSON File and Video into Strategic Wrestler (MatScout) to Add Modifiers, Save Stats, Analyze Data, and Create Training Plans

Import Events and Rosters from Strategic Wrestler to Minimize Setup on MatSide, be Ready to Go Come Match Time.
